# 获取单值网格的最小操作数

> [!question] 题目描述
> ![]()

---

> [!light] 核心思路
> **破局点**：每次操作都加减 `x`，所以所有元素对 `x` 的余数必须一致；在可行前提下，把所有值变到中位数对应的目标值，总代价最小。
> 1. 先把二维网格展平到一维数组 `nums`。
> 2. 检查可行性：若存在元素 `val % x` 与首元素余数不同，说明永远无法通过 `±x` 互相到达，直接返回 `-1`。
> 3. 将 `nums` 排序，取中位数 `target = nums[nums.size() / 2]` 作为统一目标值。
> 4. 累加每个元素到 `target` 的步数 `abs(val - target) / x`，即为最小操作数。

---

> [!code] 代码实现
>
> ```cpp
> # include <bits/stdc++.h>
> using namespace std;
>
> /*
>  * @lc app=leetcode.cn id=2033 lang=cpp
>  *
>  * [2033] 获取单值网格的最小操作数
>  */
>
> // @lc code=start
> class Solution {
> public:
>     int minOperations(vector<vector<int>>& grid, int x) {
>         int m = grid.size();
>         int n = grid[0].size();
>         vector<int> nums;
>          
>         for (int i = 0; i < m; ++i) {
>             for (int j = 0; j < n; ++j) {
>                 nums.push_back(grid[i][j]);
>             }
>         }
>         
>         int mod = nums[0] % x; 
>         for (int val : nums) {
>             if (val % x != mod) {
>                 return -1; 
>             }
>         }
>
>         sort(nums.begin(), nums.end());
>         int target = nums[nums.size() / 2];
>
>         int ops = 0;
>         for (int val : nums) {
>             ops += abs(val - target) / x;
>         }
>
>         return ops;
>     }
> };
> // @lc code=end
> ```
