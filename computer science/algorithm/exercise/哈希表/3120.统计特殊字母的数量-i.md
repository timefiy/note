# 统计特殊字母的数量 I

> [!question] 题目描述
> ![]()

---

> [!light] 核心思路
> **破局点**：每个字母只关心三种状态：只出现过小写、只出现过大写、两者都出现过；当状态首次变为“两者都出现过”时，答案加一。
>
> 1. 用长度为 `26` 的数组 `count` 记录每个字母状态：`0` 未出现、`1` 仅小写、`2` 仅大写、`3` 大小写都出现。
> 2. 遍历字符串，遇到小写字母时：
>    - 若该字母之前状态为 `2`，说明首次凑齐大小写，答案加一并置为 `3`；
>    - 若状态不是 `3`，更新为 `1`。
> 3. 遇到大写字母时同理：
>    - 若之前状态为 `1`，答案加一并置为 `3`；
>    - 若状态不是 `3`，更新为 `2`。
> 4. 遍历结束返回答案。

---

> [!code] 代码实现
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
>
> /*
>  * @lc app=leetcode.cn id=3120 lang=cpp
>  *
>  * [3120] 统计特殊字母的数量 I
>  */
>
> // @lc code=start
> class Solution {
> public:
>     int numberOfSpecialChars(string word) {
>         int ans = 0;
>
>         vector<int> count(26, 0);
>         for (char c : word) {
>             if (c >= 'a' && c <= 'z') {
>                 if(count[c - 'a'] == 2){
>                     ans++;
>                     count[c - 'a'] = 3;
>                 }
>
>                 if(count[c - 'a'] != 3){
>                     count[c - 'a'] = 1;
>                 }
>             }
>             if (c >= 'A' && c <= 'Z') {
>                 if(count[c - 'A'] == 1){
>                     ans++;
>                     count[c - 'A'] = 3;
>                 }
>
>                 if(count[c - 'A'] != 3){
>                     count[c - 'A'] = 2;
>                 }
>             }
>         }
>         return ans;
>     }
> };
> // @lc code=end
> ```
