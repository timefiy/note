# 完成所有任务的最少初始能量

> [!question] 题目描述
> ![]()

---

> [!light] 核心思路
> **破局点**：为了尽量减少初始能量，应该优先做“启动门槛高但实际消耗低”的任务，即按 `minimum - actual` 从大到小排序。
> 1. 对每个任务 `task = [actual, minimum]`，计算“门槛余量” `minimum - actual`，按这个值降序排序。
> 2. 用 `current` 记录当前已有能量，`res` 记录至少需要准备的初始能量。
> 3. 遍历任务时，如果 `current < minimum`，说明无法开始当前任务，需要补充 `minimum - current` 的能量，并累加到 `res`。
> 4. 任务执行后消耗 `actual`，更新 `current -= actual`。
> 5. 遍历结束后，`res` 就是完成所有任务所需的最少初始能量。

---

> [!code] 代码实现
>
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
>
> /*
>  * @lc app=leetcode.cn id=1665 lang=cpp
>  *
>  * [1665] 完成所有任务的最少初始能量
>  */
>
> // @lc code=start
> class Solution {
> public:
>     int minimumEffort(vector<vector<int>>& tasks) {
>         // 自定义排序：按照 minimum - actual 的差值降序排序
>         sort(tasks.begin(), tasks.end(), [](const vector<int>& a, const vector<int>& b) {
>             return (a[1] - a[0]) > (b[1] - b[0]);
>         });
>
>         int res = 0;     // 需要的最少初始能量
>         int current = 0; // 当前遍历过程中拥有的能量
>
>         for (const auto& task : tasks) {
>             int actual = task[0];
>             int minimum = task[1];
>
>             // 满足进入所需的能量
>             if (current < minimum) {
>                 res += (minimum - current); // 需要增加的能量
>                 current = minimum;          // 补充后，当前能量刚好达到 minimum
>             }
>             
>             // 消耗能量
>             current -= actual;
>         }
>
>         return res;
>     }
> };
> // @lc code=end
> ```
