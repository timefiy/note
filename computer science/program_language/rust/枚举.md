# 枚举

枚举（`enum`）用于把“某类事物的不同情况”用不同分支表示。Rust 通过 `match` 对枚举进行分支处理。

## 基本定义

```rust
#[derive(Debug)]
enum Book {
    Papery,
    Electronic,
}

fn main() {
    let book = Book::Papery;
    println!("{:?}", book);
}
```

## 枚举变体携带数据

枚举变体可以带：

- 元组风格数据：`Variant(T1, T2, ...)`
- 结构体风格数据：`Variant { field1: T1, field2: T2, ... }`

### 元组风格

```rust
enum Book {
    Papery(u32),
    Electronic(String),
}

let book = Book::Papery(1001);
let ebook = Book::Electronic(String::from("url://..."));
```

### 结构体风格

```rust
enum Book {
    Papery { index: u32 },
    Electronic { url: String },
}

let book = Book::Papery { index: 1001 };
```

## match 语法

`match` 用于根据枚举（或其他可匹配类型）选择不同分支执行；如果没有“兜底”，代码无法通过编译。

```rust
enum Book {
    Papery { index: u32 },
    Electronic { url: String },
}

let book = Book::Papery { index: 1001 };

match book {
    Book::Papery { index } => {
        println!("Papery book {}", index);
    }
    Book::Electronic { url } => {
        println!("E-book {}", url);
    }
}
```

`match` 也可以作为表达式使用（返回值的所有分支类型必须一致）：

```rust
enum Num {
    Small(i32),
    Big(i32),
}

fn main() {
    let n = Num::Small(10);
    let text = match n {
        // format! 是在内存中（堆上）动态拼接并生成一个新的 String 字符串对象。
        Num::Small(v) => format!("small: {}", v),
        Num::Big(v) => format!("big: {}", v),
    };
    println!("{}", text);
}
```

### 非枚举匹配与兜底

```rust
fn main() {
    let t = "abc";
    match t {
        "abc" => println!("Yes"),
        _ => {}
    }
}
```

## Option 枚举

Rust 用 `Option<T>` 表示“可能有值 / 可能没有值”，用于替代语言层面的 `null`。

```rust
enum Option<T> {
    Some(T),
    None,
}
```

匹配 `Option`：

```rust
fn main() {
    let opt = Option::Some("Hello");

    match opt {
        Option::Some(something) => println!("{}", something),
        Option::None => println!("opt is nothing"),
    }
}
```

若初始值为空，类型需要显式标注：

```rust
fn main() {
    let opt: Option<&str> = Option::None;

    match opt {
        Option::Some(something) => println!("{}", something),
        Option::None => println!("opt is nothing"),
    }
}
```

## if let 语法糖

当你只关心 `match` 的其中一种情况时，可用 `if let` 简化。

```rust
fn main() {
    let i = 0;
    if let 0 = i {
        println!("zero");
    } else {
        println!("not zero");
    }
}
```

对枚举也同样适用：

```rust
enum Book {
    Papery(u32),
    Electronic(String),
}

fn main() {
    let book = Book::Electronic(String::from("url"));
    if let Book::Papery(index) = book {
        println!("Papery {}", index);
    } else {
        println!("Not papery book");
    }
}
```
