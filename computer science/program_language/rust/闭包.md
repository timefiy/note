# Rust 闭包总结

## 定义

闭包是匿名函数，可捕获并使用其所在作用域中的变量；闭包可以被存储、作为参数传递，甚至作为返回值。

## 闭包与函数区别

- 匿名性：闭包匿名，可存为变量；函数有固定名称
- 环境捕获：闭包可捕获外部变量；函数不能直接捕获外部变量
- 类型：闭包可由编译器推导（常见场景）；函数参数/返回通常更显式
- 使用：闭包常用于回调、迭代器、事件驱动逻辑等

## 声明与调用

语法：`let f = |参数| { 表达式或语句块 };`

- 可省略参数类型（由上下文推导）
- 闭包可有零个或多个参数
- 调用方式：像函数一样 `f(...)`

## 捕获外部变量

闭包可使用三种方式捕获外部变量：

- 按引用捕获（默认）：`|...| ...` 使用外部变量的借用
- 按值捕获：使用 `move`，把外部变量所有权移动到闭包内部
- 可变借用捕获：闭包对捕获变量进行修改时需要可变借用（同时闭包相关参数/变量需匹配）

## 移动与借用现象

- 默认按引用捕获时，外部变量通常仍可继续使用
- 使用 `move` 后，外部变量的所有权会转移，外部作用域中的原变量可能不可再使用
- 若闭包需要修改捕获变量，则闭包环境捕获必须满足可变访问要求

## 闭包作为参数：Fn / FnMut / FnOnce

闭包根据其对捕获变量的需求自动实现对应特征：

- `Fn`：不修改捕获的变量，闭包可多次调用
- `FnMut`：修改捕获的变量，闭包可多次调用
- `FnOnce`：获取捕获变量所有权，只能调用一次

## 闭包在迭代器中常见用法

闭包经常作为迭代器适配器的参数（如 `map`、`filter` 等），用于对集合元素进行转换或筛选。

## 返回闭包

函数可以返回闭包类型；常见做法：

- 使用 `impl Fn...` 返回（当返回类型可静态确定时）
- 使用 `Box<dyn Fn...>` 返回（当需要动态分发或类型不易直接写清时）
