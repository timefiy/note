# Rust 函数学习笔记

- 声明函数使用关键字fn
- 函数名通常使用小写字母和下划线命名（snake_case）
- 函数体由花括号 `{}` 包围
- 参数
    - 函数的参数必须显式标注，多个参数之间用逗号隔开
- 返回值
    - 函数可以有返回值，使用 `->` 指定返回类型
    - 如果没有返回值，返回类型为 `()`

```rust
fn function_name(parameter1: Type1, parameter2: Type2) -> ReturnType {
    // 函数体
    return result;
}

// 3 + 2 表达式,返回值为5
// 3 + 2 ; 语句，返回值为（）

// 没有return时，最后一个表达式的值作为返回值
```
