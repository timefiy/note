# Rust 数据类型学习笔记

Rust 是一门静态编译语言，在编译时必须知道所有变量的类型

- 基于使用的值进行类型推断
- 如果可能的值类型比较多，编译器需要明确类型以确保安全

## 标量类型

- 整数类型
  - 有符号整数：i8, i16, i32(默认数据类型), i64, i128
  - 无符号整数：u8, u16, u32, u64, u128
 - isize / usize：与指针同位宽的整数（32 位架构为 32 位，64 位架构为 64 位）
  - usize（无符号）常用于数组/切片索引与长度，范围为 `0..=usize::MAX`
  - isize（有符号）常用于需要带符号的偏移量场景
- 浮点类型
  - f32：单精度浮点数
  - f64：双精度浮点数（默认类型）
- 布尔类型
  - true / false
- 字符类型
  - char：Unicode 标量值，4字节,单引号

**数值操作**

- 加法、减法、乘法、除法、取模运算符：`+`、`-`、`*`、`/`、`%`
- 溢出行为：在 debug 模式下会 panic，在 release 模式下会进行环绕（wrap around）

**整数类型**

*整数溢出*：当整数超出其类型的最大值时会发生溢出。例如，u8 类型的最大值是 255，如果尝试将其增加 1，就会发生溢出。在编译时就会检测到这种错误。在release模式下会将溢出值减去最大值（即循环回到最小值），从而得到一个有效的结果。在build时会进行溢出报错

## 复合类型

将多个值组合成一个复合类型

- 元组类型
- 数组类型

### 元组类型

元组是将多个**不同**类型的值组合在一起的复合类型。元组的大小在编译时是固定的。

```rust
let tup = (500, 6.4, 1);  // 用圆括号"()"定义，元素之间用逗号分隔

println!("{:?}", tup);
println!("第一个元素: {}", tup.0);
println!("第二个元素: {}", tup.1);
println!("第三个元素: {}", tup.2);
```

**元组越界**：访问超出元组长度的元素会导致编译错误。

### 数组类型

数组是将**相同**类型的多个值组合在一起的复合类型。数组的大小在编译时是固定的。

```rust
let arr = [1, 2, 3, 4, 5];  // 定义一个包含5个i32元素的数组，类型推断为[i32; 5]

let a = [3; 5];  // 定义一个包含5个元素的数组，所有元素都是3

println!("{:?}", arr);

println!("{:?}", a);

// 访问数组元素
println!("第一个元素: {}", arr[0]);
println!("第二个元素: {}", arr[1]);
```

**数组越界**：访问超出数组长度的元素会导致运行时panic。（编译会通过）

**数组用处**：存放在栈上而不是堆上，或者用于需要固定大小集合的场景
