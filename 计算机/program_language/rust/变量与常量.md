# Rust 变量与常量学习笔记

## 常量声明

```rust
const MAX_POINTS: u32 = 1_000;
```

- **常量**使用 `const` 关键字声明
- 常量**必须显式指定类型**（如 `:u32`），不能依赖类型推断
- 常量名通常使用全大写字母和下划线命名（SCREAMING_SNAKE_CASE）
- 数字字面量可以使用下划线 `_` 分隔，提高可读性（1_000 等同于 1000）
- 常量在整个程序运行期间都有效，存在于声明它们的作用域中

## 变量的可变性

### 不可变变量

```rust
let y = 10;
```

- Rust 中的变量默认是**不可变**的（immutable）
- 使用 `let` 关键字声明的变量默认不能被重新赋值
- 尝试修改不可变变量会导致编译错误

### 可变变量

```rust
let mut x = 5;
x = 6;  // 可以修改
```

- 使用 `mut` 关键字可以声明**可变变量**（mutable）
- 可变变量的值可以在后续代码中被修改
- `mut` 关键字显式表明该变量在程序中会被改变

## 变量遮蔽（Shadowing）

```rust
let y = 10;
let y = 20;
```

- 使用 `let` 关键字可以重新声明同名变量，这称为**变量遮蔽**
- 第二个 `y` 会遮蔽第一个 `y` 的值
- 输出结果为 `20`

### 变量遮蔽与类型转换

```rust
let string = "     ";
let string = string.len();
```

- 变量遮蔽允许改变变量的**类型**
- 第一个 `string` 是字符串字面量类型 `&str`
- 第二个 `string` 是 `usize` 类型（`.len()` 返回的类型）
- 输出结果为 `5`（5个空格字符）
