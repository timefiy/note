# Rust 变量与常量学习笔记

## 数据类型

Rust 是一门静态编译语言，在编译时必须知道所有变量的类型  

- 基于使用的值进行类型推断
- 如果可能的值类型比较多，编译器需要明确类型以确保安全

### 标量类型

- 整数类型
  - 有符号整数：i8, i16, i32(默认数据类型), i64, i128
  - 无符号整数：u8, u16, u32, u64, u128
  - 根据系统架构决定默认整数类型：isize（有符号）/ usize（无符号）(32位系统默认i32，64位系统默认i64)
- 浮点类型
  - f32：单精度浮点数
  - f64：双精度浮点数（默认类型）
- 布尔类型
  - true / false
- 字符类型
  - char：Unicode 标量值，4字节,单引号

**数值操作**  

- 加法、减法、乘法、除法、取模运算符：`+`、`-`、`*`、`/`、`%`  
- 溢出行为：在 debug 模式下会 panic，在 release 模式下会进行环绕（wrap around）  

**整数类型**  
*整数溢出*：当整数超出其类型的最大值时会发生溢出。例如，u8 类型的最大值是 255，如果尝试将其增加 1，就会发生溢出。在编译时就会检测到这种错误。在release模式下会将溢出值减去最大值（即循环回到最小值），从而得到一个有效的结果。在build时会进行溢出报错》

### 复合类型

将多个值组合成一个复合类型

- 元组类型
- 数组类型

#### 元组类型

元组是将多个**不同**类型的值组合在一起的复合类型。元组的大小在编译时是固定的。

```rust
let tup = (500, 6.4, 1);  // 用圆括号"()"定义，元素之间用逗号分隔

println!("{:?}", tup);
println!("第一个元素: {}", tup.0);
println!("第二个元素: {}", tup.1);
println!("第三个元素: {}", tup.2);
```

**元组越界**：访问超出元组长度的元素会导致编译错误。

#### 数组类型

数组是将**相同**类型的多个值组合在一起的复合类型。数组的大小在编译时是固定的。

```rust
let arr = [1, 2, 3, 4, 5];  // 定义一个包含5个i32元素的数组，类型推断为[i32; 5]

let a = [3; 5];  // 定义一个包含5个元素的数组，所有元素都是3

println!("{:?}", arr);

println!("{:?}", a);

// 访问数组元素
println!("第一个元素: {}", arr[0]);
println!("第二个元素: {}", arr[1]);
```

**数组越界**：访问超出数组长度的元素会导致运行时panic。（编译会通过）

**数组用处**：存放在栈上而不是堆上，或者用于需要固定大小集合的场景

## 常量声明

```rust
const MAX_POINTS: u32 = 1_000;
```

- **常量**使用 `const` 关键字声明
- 常量**必须显式指定类型**（如 `:u32`），不能依赖类型推断
- 常量名通常使用全大写字母和下划线命名（SCREAMING_SNAKE_CASE）
- 数字字面量可以使用下划线 `_` 分隔，提高可读性（1_000 等同于 1000）
- 常量在整个程序运行期间都有效，存在于声明它们的作用域中

## 变量的可变性

### 不可变变量

```rust
let y = 10;
```

- Rust 中的变量默认是**不可变**的（immutable）
- 使用 `let` 关键字声明的变量默认不能被重新赋值
- 尝试修改不可变变量会导致编译错误

### 可变变量

```rust
let mut x = 5;
x = 6;  // 可以修改
```

- 使用 `mut` 关键字可以声明**可变变量**（mutable）
- 可变变量的值可以在后续代码中被修改
- `mut` 关键字显式表明该变量在程序中会被改变

## 变量遮蔽（Shadowing）

```rust
let y = 10;
let y = 20;
```

- 使用 `let` 关键字可以重新声明同名变量，这称为**变量遮蔽**
- 第二个 `y` 会遮蔽第一个 `y` 的值
- 输出结果为 `20`

### 变量遮蔽与类型转换

```rust
let string = "     ";
let string = string.len();
```

- 变量遮蔽允许改变变量的**类型**
- 第一个 `string` 是字符串字面量类型 `&str`
- 第二个 `string` 是 `usize` 类型（`.len()` 返回的类型）
- 输出结果为 `5`（5个空格字符）

## 函数

- 声明函数使用关键字fn
- 函数名通常使用小写字母和下划线命名（snake_case）
- 函数可以有返回值，使用 `->` 指定返回类型
- 函数体由花括号 `{}` 包围
- 函数可以有多个参数，参数之间用逗号分隔

```rust
fn function_name(parameter1: Type1, parameter2: Type2) -> ReturnType {
    // 函数体
    return result;
}

// 3 + 2 表达式,返回值为5
// 3 + 2 ; 语句，返回值为（）

// 没有return时，最后一个表达式的值作为返回值
```

## 控制流

- Rust 中的控制流包括条件表达式 `if`、循环 `while` 和 `for` 循环
- `if` 表达式是 Rust 中最基本的控制流结构
- 条件必须是布尔值，不能是其他类型

### if 表达式

```rust
if condition {
    // 条件为真时执行
} else {
    // 条件为假时执行
}

// 整个if可以堪称一个表达式
```

如果使用了多余一个else if，那么最好使用match来重构代码

### loop 循环

- `loop` 关键字创建无限循环
- 可以使用 `break` 退出循环
- 可以在 `break` 后面跟一个值，作为整个 loop 表达式的返回值

```rust
let result = loop {
    break 42;
};
```

### while 循环

- `while` 循环在条件为真时重复执行
- 条件必须是布尔值

```rust
let mut counter = 0;
while counter < 5 {
    println!("counter: {}", counter);
    counter += 1;
}
```

### for 循环

- `for` 循环用于遍历集合或范围
- 语法：`for item in collection`

```rust
for i in 1..5 {
    println!("i: {}", i);
}

for element in [1, 2, 3, 4, 5] {
    println!("element: {}", element);
}

for element in [1, 2, 3, 4, 5].iter() {
    println!("element: {}", element);
}

for (index, element) in [1, 2, 3, 4, 5].iter().enumerate() {
    println!("index: {}, element: {}", index, element);
}
```

## 方法

### parse 方法

```rust
let guess: i32 = "42".parse().expect("Not a number!");
```

- **`.parse()` 方法**用于将字符串解析为其他类型
- `.parse()` 是泛型方法，**必须提供目标类型**
- 可以通过类型注解（`:i32`）或 Turbofish 语法（`.parse::<i32>()`）指定类型
- **`.expect()`** 用于处理解析失败的情况，如果解析失败会 panic 并显示错误信息
- 常用于读取用户输入或配置文件等场景
