# 前后端学习指南

关于前后端的学习路线，分为两部分，一部分你只想打比赛，为一些项目写一些简单的后端做逻辑方面的处理，例外一部分是传统的的前后端，想靠着前后端之类的找工作。（建议大家只看第一部分就行）

## 简单的前后端

### 简短的前后端项目

- 前端
	- 前端便是基础的**html**，**css**与**javascript**。
		- html与css建议大家都花一点时间学一学，就一两天有个印象就行，后面打本份使用AI就行。js方面建议直接学习**Typescript**，如果你后面想往前后端方向走建议好好学**TypeScrpit**。
	- 在很多硬件、嵌入式、物联网（IoT）比赛或科研项目中，你往往需要做一个“软件”去和单片机（如 STM32、Arduino、ESP32）进行串口通信、数据可视化或下发控制指令，这个软件就是**上位机**
		- 建议学习**pyqt**，开发速度够快。
		- 闲着没事学c++的qt。
	- 闲着没事可以研究一下微信小程序的开发
- 后端
	- 在学习后端方面建议先学一学计网的基础知识，要不然你学的时候会觉得云里雾里的，不知道为什么要这么写。[学习文章推荐](https://www.runoob.com/w3cnote/summary-of-network.html)
	- 快速开发的话建议学一下**FastAPI**，这个框架可以让你的设备使用**HTTP**协议进行通信。
	- 关于数据库学**MySQL**就行了，如果有些上位机的存储，性能有限可能会使用**SQLite**。但学这两者的目的其实就是掌握**SQL语句**

## 传统求职与工业级全栈路线

现在AI出来之后你要明确一点，没有后端工程师了，只有全栈工程师
其次，对比上面所说的使用python快捷开发，你要明白为什么要使用java（有些人可能听说过Go）开发，因为python开发没有解决高并发等方面的问题。
这就是你接下来要学的
- 为了是数据能在内存中持久化出现了**redis**
- 对于数据库查询可能需要动态的SQL语句而出现了**Mybatis**
- 为了解决mysql原子性的问题出现**PGSQL**
- 解决多线程的问题出现了消息队列（**RocketMQ**等）
- 防止一个服务器性能不够出现**nginx**
- 为了方便项目管理出现了**maven**
- 为了方便项目管理出现了**docker**
- 等等等等
有人说了这些东西全要学么，很不幸是的，但是你不用全部精通。
**你真正要学的，是它们的“底牌”：**
1. 明白**为什么**要用它（什么时候该用 Redis 挡伤害，什么时候该用 MQ 削峰）。
2. 理解它们的**底层核心原理**（比如 MySQL 的 B+树索引、Redis 的五种基本数据结构、Nginx 的单线程事件驱动模型）。
理解这些其实是方便你看懂日志为什么报错。因为这个时候你需要引导AI，他才能帮你解决问题。
[项目](https://github.com/xkcoding/spring-boot-demo)
想实操的话看一看，不建议大家搞什么黑马的外卖系统之类的，烂大街了。建议自己看看代码想想为什么要这么写？后面还有什么不明白就多多问问学长学姐吧
